# Smart Bala - PWA Мобильное Приложение

Это прогрессивное веб-приложение (PWA) для поддержки детей с аутизмом.

## Особенности мобильного приложения

✅ **Установируется как нативное приложение** на телефон или планшет  
✅ **Работает офлайн** - сохраняет данные при отсутствии интернета  
✅ **Иконка приложения** на главном экране  
✅ **Полноэкранный режим** - без адресной строки браузера  
✅ **Кеширование** - быстрая загрузка  

## Как установить на мобильное устройство

### На Android:
1. Откройте приложение в Chrome
2. Нажмите на меню ⋮ (три точки)
3. Выберите "Установить приложение" или "Add to Home screen"
4. Подтвердите установку

### На iOS (iPhone/iPad):
1. Откройте приложение в Safari
2. Нажмите кнопку поделиться (значок стрелки)
3. Выберите "На экран Домой"
4. Введите имя приложения (Smart Bala)
5. Подтвердите

## Запуск в разработке

\`\`\`bash
npm install      # Установить зависимости
npm run dev      # Запустить сервер разработки (localhost:3000)
npm run build    # Собрать для продакшена
npm run preview  # Просмотр собранного приложения
\`\`\`

## PWA Конфигурация

Приложение настроено с использованием:
- **manifest.json** - метаинформация приложения
- **Service Worker** - обработчик офлайн-режима и кеширования  
- **Vite PWA Plugin** - автоматическая генерация PWA ассетов

## Иконка приложения

Иконка приложения находится:
- `public/favicon.jpg` - используется как аватар приложения (192x192 и 512x512)

## Сборка для мобильных платформ

Если нужны настоящие нативные приложения:

```bash
# Для iOS и Android с помощью Capacitor
npm install @capacitor/core @capacitor/cli
npx cap init SmartBala com.smartbala.app
npm run build
npx cap add ios
npx cap add android
```
